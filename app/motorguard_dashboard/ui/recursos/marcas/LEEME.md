# Logotipos de los modelos de lenguaje

SVG de un solo color tomados de **Simple Icons 16.33.0** (npm `simple-icons`, publicado el 27-sep-2026;
https://simpleicons.org), licencia **CC0 1.0** para los archivos. Descargados el 13-oct-2026 de
`https://cdn.jsdelivr.net/npm/simple-icons@16.33.0/icons/<nombre>.svg`.

Las marcas y logotipos pertenecen a sus dueños (Anthropic, Alibaba/Qwen, Google, Mistral AI, DeepSeek,
OpenRouter, Ollama). La app los usa sin modificarlos, solo para indicar qué modelo genera cada respuesta; no
implica respaldo ni relación con esas empresas. Simple Icons no incluye el logotipo de OpenAI: para ese
proveedor y para cualquier otro sin logotipo, la app usa su ícono genérico del asistente.
